# Mon carnet

Carnet de suivi IMO pour iPhone : repas (avec repères FODMAP), ressenti, selles (échelle de Bristol), cures avec prises à cocher, rappels Calendrier, bilan et PDF pour le médecin.

## Mise en ligne
Héberger ce dossier tel quel sur n'importe quel hébergeur HTTPS statique (GitHub Pages, Netlify, Cloudflare Pages).

## Installation sur l'iPhone
1. Ouvrir l'adresse dans **Safari**.
2. Bouton Partager → **Sur l'écran d'accueil**.
3. Ouvrir l'app depuis l'icône (et non depuis Safari) : les données y sont conservées durablement.

## Données
Tout est stocké sur le téléphone, rien n'est envoyé ailleurs. Bilan → Sauvegarder pour exporter un fichier de sauvegarde.

## Mise à jour
Après avoir modifié les fichiers, changer `VERSION` dans `sw.js`.
